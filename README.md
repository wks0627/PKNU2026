# 울산 아너 소사이어티 아카이브

울산사회복지공동모금회 모금사업팀 개인모금 파트장 **우길산**의 개인 업무 도구입니다.
불특정 다수를 향한 홍보 페이지가 아니라, **상담에 필요한 자료를 담아두고 꺼내 쓰는 서재**입니다.

- 1차 사용자: 담당자 본인 — 상담 중에 열어놓고 씀
- 2차 사용자: 상담 자리의 기부자 — 화면을 함께 보며 설명
- 분위기: 박물관 전시실 + 기록관 서가

## 메뉴 구성

상단 메뉴가 화면을 전환합니다 (해시 라우팅). 끝없이 스크롤하지 않습니다.

| 메뉴 | 주소 | 무엇을 하는 곳인가 |
|---|---|---|
| (첫 화면) | `#home` | 공식 캠페인 이미지 + 캠페인 영상 + 빠른 진입 |
| 현황과 연혁 | `#status` | 인용 가능한 숫자와 제도 근거 |
| 명예의전당 | `#hall` | 울산박물관 전당 배너 + 1호~150호 **금빛** 명패 |
| 메모리얼 아너스 | `#memorial` | 1호~150호 **은빛** 명패 + 추모 배경 + 헌화 |
| 상담 데스크 | `#desk` | **상담 중에 실제로 쓰는 도구** + 서식 |
| 복지동향 | `#news` | 아너 소사이어티 기부 뉴스. 제목 클릭 시 원문 열람 |
| 담당자 | `#me` | 기부자께 보여드리는 소개 화면 |

`index.html#desk` 처럼 특정 화면 링크를 바로 공유할 수 있습니다.

### 이미지 — 원본 그대로 사용

| 파일 | 쓰이는 곳 |
|---|---|
| `assets/img/logo.png` | 공식 사랑의열매 로고. 상단 바와 푸터. 어두운 배경에서는 흰 판 위에 올림 |
| `assets/img/home-brand.jpg` | 첫 화면 — 공식 브랜드 모델 캠페인 이미지 |
| `assets/img/hall-poster.jpg` | 명예의전당 상단 배너 |
| `assets/img/hall.jpg` | 명패 질감 / 메모리얼 배경 (어둡게 깔림) |

인물·문구·디자인 요소는 손대지 않습니다. 잘리지 않도록 `object-fit: contain` 으로 두고
남는 여백만 이미지와 같은 색으로 채웁니다.

### 캠페인 영상

첫 화면 하단. `index.html` 의 `#player` 에 `data-yt="MoSUxTgNmak"` 로 지정합니다.
썸네일만 먼저 올리고 **누를 때** 유튜브를 불러옵니다 — 페이지를 열자마자 외부 요청이 나가지 않습니다.

## 기능

### 상담 데스크 — 이 사이트의 핵심

- **약정 계산기** — 총액·기간·최초 가입금액을 넣으면 연도별 납입 계획표와
  세액공제 추정, 실부담액이 즉시 나옵니다. 프리셋 4종 (1억/5년, 1억/3년, 1억 일시, 2억/5년).
- **진행 체크리스트** — 사전·상담·후속 13개 항목. 체크 상태가 이 컴퓨터에 저장됩니다.
- **자주 막히는 지점** — "금액이 부담된다", "이름이 알려지는 게 싫다" 등 6가지 반론과 대응.
- **질문 찾기** — 질문·답변 본문까지 실시간 검색.
- **문자 틀** — 상담 후 감사, 서식 발송, 헌액 안내. 복사 버튼 있음.

### 명예의전당

1호부터 150호까지 **한 페이지에 연번으로** 펼칩니다(연도별로 나누지 않음).
호수·성함 검색, 성함공개/미등록 필터. 명패를 누르면 오른쪽에서 상세 시트가 열립니다.
사진이 없는 호수는 명예의전당 이미지가 명패에 은은하게 비칩니다.

### 메모리얼 아너스

명예의전당과 같은 1호~150호 체계를 쓰되 **명패를 은빛으로** 구분합니다.
배경은 전당 사진을 흑백·저휘도로 깊게 눌러 벽의 결만 남기고, 천창에서 빛이 내려오는 결을 더했습니다.
`familyConsent: true` 인 호수만 내용이 차고, 나머지는 `—` 로 비어 있습니다.
명패를 누르면 에피타프와 헌화 버튼이 열립니다.

## 세액공제 계산 근거

`data/honor.js` 의 `tax.rates` 를 고칩니다. 현재 설정은 1천만원 이하 15%, 초과분 30%.

```
2,250만원 납입 → 1,000만 × 15% + 1,250만 × 30% = 525만원
```

> 화면에 "세무 전문가 확인 필요" 문구가 항상 함께 나옵니다. 확정 금액이 아닙니다.

### 왜 `.json` 이 아니라 `.js` 인가

브라우저는 보안상 `file://` 에서 `.json` 을 읽지 못합니다(`fetch` 차단).
바탕화면 바로가기로 더블클릭해 여는 방식을 유지하려면 `.js` 여야 합니다.
내용 형식은 JSON 과 같고 앞에 `HONOR.xxx =` 만 붙습니다.

### 코드 구조 (main.js)

```
1) 순수 함수   range, pipe, matches, maskName, buildSchedule,
               taxCredit, filterLibrary, buildPlates, filterPlates
               → DOM 을 건드리지 않음. 입력이 같으면 출력이 같음
2) DOM 도우미  $, $$, html, text, store
3) 라우터/인트로
4) 화면별 렌더러
```

콘솔에서 `HONOR_FN.buildSchedule(100000000, 5, 10000000)` 처럼 계산 함수를 바로 호출할 수 있습니다.

## 개인정보 — 기본값은 "동의 없으면 비노출"

| 대상 | 필수 조건 | 없을 때 |
|---|---|---|
| 명패 성함 | 본인 공개 동의 | "비공개" 표시 |
| 추모 기록 | `familyConsent: true` | **목록에서 아예 제외** |
| 추모 성함 | `visibility` 필수 | `public` 실명 / `initial` 홍○○ / `private` 비공개 |
| 상담 사례 | `consent: true` | 목록에서 제외 |

> **GitHub 저장소는 반드시 Private.** 담당자 메모와 회원 정보가 들어갑니다.

## 해야 할 일

1. `assets/img/profile.jpg` — 담당자 사진 (세로 3:4)
2. `data/hall.js` 의 `plates` — 호수별 성함·사진·메모 (확보되는 대로)
3. `data/stats.js` — `ulsan`, `distribution` 의 `verified` 를 `true` 로
   (`false` 인 동안 화면에 "검증 전 임시 수치" 경고 표시)
4. `assets/files/*.pdf` — 서식 파일. 넣은 뒤 `data/library.js` 의 `ready` 를 `true` 로
