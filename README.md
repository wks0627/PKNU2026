# 울산 아너 소사이어티 · 담당자 소개 홈페이지

울산사회복지공동모금회 모금사업팀 개인모금 파트장 **우길산**의 담당자 소개 페이지입니다.
아너 소사이어티 가입을 고민하는 분이 결정에 앞서 참고할 자료를 모아두는 것이 목적입니다.

- 성격: 비상업적 업무용 / **공개 영역만** 구성 (내부 업무용 비공개 영역은 만들지 않음)
- 톤: 다큐멘터리형 — 울산박물관 아너 명예의전당을 모티프로 한 웅장·기품
- 열람: 위에서 아래로 스크롤하며 읽는 구조. 오른쪽 점 네비게이션과 상단 진행 바로 현재 위치를 알 수 있습니다.

## 파일 구성

```
index.html                  화면 구조 (내용은 전부 data/ 에서 불러옴)
assets/css/style.css        디자인
assets/js/main.js           렌더링·차트·상호작용 (외부 라이브러리 없음)
assets/img/hall-poster.jpg  첫 화면을 채우는 명예의전당 포스터
assets/img/hall.jpg         좁은 화면(모바일)용 배경
assets/img/profile.jpg      담당자 사진 ← 아직 없음
assets/files/*.pdf          자료실 서식 ← 아직 없음
data/_init.js               ★ 가장 먼저 읽혀야 함
data/*.js                   섹션별 데이터
```

### 왜 `.json` 이 아니라 `.js` 인가

브라우저는 보안상 `file://` 에서 `.json` 을 읽지 못합니다(`fetch` 차단).
**바탕화면 바로가기로 더블클릭해 여는 방식**을 유지하려면 데이터가 `.js` 여야 합니다.
내용 형식은 JSON 과 동일하고, 앞에 `HONOR.xxx =` 만 붙어 있습니다.
나중에 웹서버(GitHub Pages 등)로만 운영하기로 하면 `.json` 으로 바꿀 수 있습니다.

## 개인정보 — 반드시 지켜야 할 규칙

이 사이트는 **동의가 없으면 아무것도 보여주지 않는 쪽**을 기본값으로 잡았습니다.

| 대상 | 필수 조건 | 없을 때 |
|---|---|---|
| 명패 월 성함 | 기부자 본인 공개 동의 | "비공개" 표시 |
| 나눔 스토리 | `consent: true` | 아예 목록에서 제외 |
| 추모의 벽 | `familyConsent: true` | 아예 목록에서 제외 |
| 추모 성함 | `visibility` 필수 | `public` 실명 / `initial` 홍○○ / `private` 비공개 |
| 수혜기관명 | 기관 공개 동의 | 기관 수만 표시 |

> 회원·유족 정보가 들어가므로 **GitHub 저장소는 반드시 Private** 으로 두십시오.

## 해야 할 일

1. **담당자 사진** — `assets/img/profile.jpg` (세로 3:4, 예 900×1200px).
   없으면 "우길산" 금색 명패로 자동 대체됩니다.

2. **울산 수치 교체** — `data/archive.js` 의 `rows` 를 내부 자료로 바꾸고
   `verified` 를 `true` 로. `false` 인 동안 화면에 "검증 전 임시 수치" 안내가 뜹니다.

3. **배분 실적 교체** — `data/impact.js` 도 동일하게 `verified: true` 로.

4. **자료실 PDF** — `assets/files/` 에 파일을 넣고 `data/downloads.js` 의
   `ready` 를 `true` 로 바꾸면 내려받기가 열립니다.

5. **스토리·추모 기록** — 동의를 받은 뒤 `stories.js` / `memorial.js` 에 추가.
