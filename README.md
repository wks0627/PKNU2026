# 울산 아너 소사이어티 · 담당자 소개 홈페이지

울산사회복지공동모금회 모금사업팀 개인모금 파트장 **우길산**의 담당자 소개 페이지입니다.
아너 소사이어티 가입을 고민하는 분이 결정에 앞서 참고할 자료를 모아두는 것이 목적입니다.

- 성격: 비상업적 업무용
- 톤: 다큐멘터리형 (울산박물관 명예의전당을 모티프로 한 웅장·기품)
- 아카이브: 울산 회원 가입 현황 / 약정 금액 추이 / 연도별 원장

## 파일 구성

```
index.html              페이지 본문 (구조만, 숫자는 데이터에서 불러옴)
data/honor-data.js      ★ 모든 수치·FAQ·연혁을 관리하는 파일
assets/css/style.css    디자인
assets/js/main.js       차트 렌더링 및 상호작용 (외부 라이브러리 없음)
assets/img/profile.jpg  담당자 사진 (넣어야 함)
assets/img/hall.jpg     명예의전당 배경 사진 (넣어야 함)
```

## 해야 할 일

1. **사진 2장 넣기**
   - `assets/img/profile.jpg` — 담당자 사진. 세로 3:4 비율 권장 (예: 900×1200px).
     없으면 이름이 들어간 금색 명패로 자동 대체됩니다.
   - `assets/img/hall.jpg` — 울산박물관 명예의전당 사진. 가로로 넓은 사진 권장 (예: 2000×1200px).
     없으면 열주(기둥) 느낌의 CSS 배경만 보입니다.

2. **울산 수치 교체**
   `data/honor-data.js` 의 `ulsan.rows` 를 실제 내부 자료로 바꾸고,
   `ulsan.verified` 를 `true` 로 변경하세요. `false` 인 동안에는 화면에
   "검증 전 임시 수치" 안내가 표시됩니다.

   ```js
   { year: 2025, members: 138, newMembers: 6, amount: 6.0 }
   //            누적 회원      신규 가입        신규 약정(억원)
   ```

3. 연혁·FAQ 문구도 같은 파일에서 수정합니다.

## 보는 방법

`index.html` 을 더블클릭하면 됩니다. 빌드 과정이 없고, 외부 라이브러리를
받아오지 않으므로 인터넷 없이도 열립니다 (웹폰트만 온라인에서 불러옵니다).

## GitHub 올리기

```bash
git init
git add .
git commit -m "울산 아너 소사이어티 담당자 소개 페이지"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

저장소 Settings → Pages → Branch 를 `main` / `/ (root)` 로 지정하면
`https://<계정>.github.io/<저장소>/` 주소로 바로 공개됩니다.

> 공개 저장소에 올릴 경우 전화번호·이메일이 그대로 노출됩니다.
> 내부용으로만 쓰실 경우 저장소를 **Private** 으로 만드시는 것을 권합니다.
